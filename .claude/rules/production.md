## 本番環境での作業ルール

- 本番環境のファイルを追加/編集/削除する場合は、毎回必ずどのような内容の作業を行うか共有し、ユーザーの確認を得てから実行すること
- 本番環境への変更は慎重に行い、影響範囲を事前に説明すること
- 本番環境へのデプロイ前には、必ず変更内容をレビューし、ユーザーの承認を得ること
- 緊急性がない限り、本番環境での直接的な変更は避け、開発環境でテスト後にデプロイすること
- 本番環境でのデプロイ・作業開始前にメンテナンスモードを有効にし、作業完了後に必ず解除すること
  - 有効化: 本番サーバーのリポジトリ直下で `bash scripts/maintenance-mode.sh on`
  - 解除: `bash scripts/maintenance-mode.sh off`（現在値の確認は `status`）
  - スクリプトは `.env` の `MAINTENANCE_MODE` を書き換え、gunicorn を `up -d` で作り直し、Django が実際に読んだ値まで確認する。
    `restart` では環境変数が反映されないため、`.env` の手編集＋restart は使わない（2026-10-26 にこれで効いていなかった）
  - メンテナンス中もスタッフユーザーは通常画面を閲覧できる。公開側の確認はログアウト状態で503になることを見る
